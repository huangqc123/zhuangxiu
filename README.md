# 装修材料计算器

一个可直接导入微信开发者工具的纯前端小程序。项目没有服务器依赖，不要求登录，计算参数、收藏和历史记录仅保存在用户当前设备。

## 首版功能

- 地砖：矩形排布、损耗、箱数、瓷砖胶、填缝剂
- 墙砖：净墙面积、砖片、箱数及铺贴辅料
- 木地板：包数、采购面积、踢脚线和防潮地膜
- 乳胶漆：墙顶展开、面漆、底漆和腻子
- 壁纸：裁切余量、花距对齐、条数和整卷采购
- 防水涂料：地面、墙面上翻、遍数和整桶采购
- 吊顶：面板排布、收边条、主次龙骨和吊点概算
- 砌墙：砌块模数、墙体体积和砌筑砂浆
- 找平砂浆：湿体积、干料系数、水泥和砂
- 混凝土：净方量、备料方量和名义配比拆料

此外包含：工具搜索、常用收藏、示例参数、高级参数摘要、本地历史、记录位置命名、历史参数复用、预算恢复、结果自动定位、矩形材料双向排布比较、采购清单复制、计算结果参数化分享、材料单价与预算汇总、计算过程、使用帮助、好友分享、意见反馈、用户协议和隐私政策。

## 导入运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本目录 `D:\code\装修材料计算器`。
3. 首次本地预览可使用测试号；正式发布前，把 `project.config.json` 中的 `appid` 替换为实际小程序 AppID。
4. 编译后从首页选择任意工具即可计算。

## 测试

## 计算边界

本项目区分“理论净量”“施工损耗”和“整包装采购量”。默认参数是常见场景的可编辑起点，并非国家统一材料消耗定额。包装面积、覆盖率、单位用量、系统构造和设计厚度应优先采用实际产品资料。

主结果会标明当前属于净工程量、含损耗需求还是整包装采购量。输入值超出常见住宅场景时，小程序会提示复核数值与单位；用户确认后仍可用于大空间或特殊工程计算。

吊顶锚固、防水构造、结构混凝土、承重砌体、防火及材料性能等涉及设计和安全的内容，不由本小程序判定。
